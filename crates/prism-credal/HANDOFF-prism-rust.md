# PRISM Stage 1 · Lane P2 handoff

The standalone Rust 2024 crate lives at `crates/prism-credal/`. The reference
checkout for this implementation was `26bc425856dbcc79c40e668c0714b3113be22872`.
The dependency lockfile was resolved from the local Cargo cache.

## Run

From `crates/prism-credal/`, build or run the CLI with Cargo. The CLI reads one
JSON value from stdin and emits one JSON verdict to stdout. Submit canonical PRISM
JSON with `decls` and `query`, or submit bytecode encoded as a JSON string.

```sh
printf '%s\n' '"HYP h [0,1] PART_EXHAUSTIVE (h) [0,1] ASK_PROB h GIVEN () q END"' |
  cargo run --quiet --locked --bin prism-credal
```

Answers include `value`, `interval`, evidence support bounds, and a sparse
conditional vertex. Rationals are reduced `"n/d"` strings, including integers.
Malformed input returns `PARSE_ERROR` as a JSON refusal. Process failure signals
an I/O or serialization error.

## Solver and certificates

- `parse_bytecode` and `Program::from_json` validate the full instruction set,
  identifier references, contexts, spans, and exact probabilities. `solve_credal`
  applies the bytecode decision rules before returning a releasable probability.
  `bound_polytope` exposes the mathematical bounds directly.
- The compiler expands the chosen partition into up to 128 atomic worlds, filters
  them with scoped deterministic links, and compiles the numerical premises into
  integer equalities. Only the query context and wildcard context enter the
  model. Conditional independence adds product constraints for subsets of the
  licensed events whose marginals are known.
- Two-phase simplex uses integer row elimination with GCD normalization and
  Bland pivots. Evidence support is optimized first. Charnes–Cooper
  homogenization then turns the conditional query into a linear objective. The
  solver optimizes at vertices and uses exact BigInt rationals for the resulting
  bounds and witnesses. An underdetermined interval carries both endpoint
  vertices. Recover the original world masses with `w = uStar / tStar`.
- Numerical infeasibility returns Farkas multipliers in `details.farkas` with
  zero-based declaration provenance in `details.rowDeclarations`. Repeated
  indices identify multiple rows generated by one declaration. The crate checks
  `yᵀA ≥ 0` and `yᵀb < 0` against the original integer rows and exposes
  `verify_farkas` for independent callers. Policy refusals carry their
  applicable evidence, such as the incompatible contexts, offending
  declarations, or exact unlicensed interval when available.
- Certain zero support preserves the JS code `DEGENERATE_PARTITION` and carries
  `ZERO_SUPPORT` in its details. `ZERO_SUPPORT_POSSIBLE` means the minimum
  evidence mass is zero and the maximum is positive.

## Verification and scope

Run `cargo test` and `cargo clippy -- -D warnings` from the crate.
The conformance test requires Node.js. It imports the live JavaScript generator
with the default bench seed `20261122` and sends all 214 programs through the
Rust CLI in both encodings. It compares exact answer strings, both interval
endpoints, evidence support bounds, and refusal codes where applicable. The
same test compares the raw Rust and JavaScript polytope verdicts.

All 200 solvable rows and all 13 kernel refusal families matched. The 14th
family, the owner-swap case, matched the JavaScript bytecode verdict through the
CLI. Its `UNSTABLE_BINDING` refusal was verified through the JavaScript
invariance gate using the positional extractor. Natural-language ownership,
license grounding, and sentence accounting are handled upstream of the Rust
bytecode CLI.

The JavaScript benchmark driver also passed when run with `write: false` to
avoid updating repository fixtures. It reported 200 exact answers, 14 trap
refusals, and zero wrong releases. Focused Rust tests additionally cover
nontrivial interval vertices, signed Farkas certificates, malformed programs,
all deterministic link relations, joint masses, context isolation, exact
posteriors, zero support, the dimension cap, and large rational operands.

The comparison covers decision parity on this corpus. Certificate vectors and
vertex choices can differ at degenerate optima. The Rust JSON parser enforces
the typed bytecode schema. Reverse-conditional diagnostics require a scoped
premise, and repeated independence operands are reduced to equivalent self
constraints and distinct subsets using integer masks.
